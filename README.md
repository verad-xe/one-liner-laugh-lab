A single short funny line answering a prompt, written for make.fun's "One-Liner Laugh Lab" bounty. The prompt it answers: the excuse a robot vacuum gives after eating a sock.

> The sock attacked first. I have the dust bunnies as witnesses.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/one-liner-laugh-lab-out python3 main.py
cat /tmp/one-liner-laugh-lab-out/entry.txt
```

The program writes one line of text (1–200 characters) to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
